# Experimental Results & Audit Captions

This directory houses the quantitative benchmark tables, error heatmaps, training curves, and side-by-side ground-truth visual comparisons for Sentinel-2 super-resolution (10m $\rightarrow$ 2.5m).

---

## 1. Ground-Truth Benchmark Results (Canonical Pipeline)

The following deliverables are generated by the audited, ground-truth-validated notebooks (`04_finetuning_experiments` and `06_full_model_experiments`):

### Output Files & Metrics Tables:
- **`sen2sr_lite_test_benchmark_metrics.csv` / `sen2sr_full_test_benchmark_metrics.csv`**:
  Quantitative sanity evaluation on $N=6$ held-out test scenes from `test_scenes.json` evaluated directly against real NAIP aerial photography:
  - **PSNR (dB)**: Evaluated on calibrated RGB surface reflectance $[0.0, 1.0]$.
  - **SSIM**: Evaluated on structural similarity across luminance, contrast, and structure.
  - **NDVI-MAE**: Mean Absolute Error on physical Normalized Difference Vegetation Index against real aerial vegetation indices.
- **`sen2sr_lite_groundtruth_6patch_comparison.png` / `sen2sr_full_groundtruth_6patch_comparison.png`**:
  Strict 4-way visual comparison:
  1. Native 10m Input (Bicubic 4×)
  2. Pretrained Baseline (2.5m)
  3. Fine-Tuned (2.5m, Ours)
  4. Real NAIP Aerial Ground Truth (VHR Reference)
  *All 4 panels strictly share the identical percentile stretch (2nd to 98th percentile) computed from the real NAIP aerial ground truth RGB.*
- **`sen2sr_lite_zoom_features.png` / `sen2sr_full_zoom_features.png`**:
  3× magnified structural zoom-in panels inspecting fine features:
  - Road Corridors and Linear Boundaries
  - Agricultural Plot Edges and Crop Furrows
  - Built-Up Clusters and Structure Footprints
- **`sen2sr_lite_error_difference_maps.png` / `sen2sr_full_error_difference_maps.png`**:
  Pixel-wise absolute error heatmaps against real aerial ground truth:
  $$\text{Error}_{\text{Base}} = |\hat{Y}_{\text{Base}} - Y_{\text{NAIP}}| \quad \text{vs} \quad \text{Error}_{\text{Fine}} = |\hat{Y}_{\text{Fine}} - Y_{\text{NAIP}}|$$
  Demonstrates where fine-tuning reduces spatial and spectral error along physical ground boundaries.
- **`test_scenes.json`**:
  Persistent geographical scene-level split recording the exact held-out test scenes for zero-leakage benchmark reproducibility.

## 2. Retrospective Audit Notes on Legacy Figures

During the comprehensive audit, earlier artifacts were analyzed and contextualized:

### 1. Legacy Figure: `SEN2SR_Joint_Validation_Comparison.png`
- **Audit Finding:** In early experiments, cropland appeared blue, and NDVI maps showed low values (~0.1–0.2) over dense vegetation.
- **Root Cause:** SEN2NAIP was loaded assuming `[Blue, Green, Red, NIR]`, whereas the physical files are natively `[Red, Green, Blue, NIR]`. Red and Blue were inadvertently swapped into the model and swapped again during display.
- **Resolution:** The entire repository has been refactored to the standardized canonical `[Red, Green, Blue, NIR]` order, matching the official `tacofoundation/SEN2SRLite` contract. Farmland renders in natural green/soil tones, and NDVI maps reflect true physical vegetation response (~0.6–0.85).

### 2. Legacy Figure: `SEN2SR_4Way_1Meter_Comparison.png` & Metrics `SEN2SR_4Way_1Meter_Metrics.csv`
- **Audit Finding:** Panel 4 (Cascaded Stage 2 1.25m) claimed "+87.08% sharpness" (RGB Acuity 0.12336), but was visibly overexposed/washed out. Tenengrad gradient metrics were inflated by contrast stretching rather than real sub-meter spatial accuracy, while NDVI edge acuity actually decreased (0.07711 $\rightarrow$ 0.06751).
- **Physical Reason:** The Stage 2 model was trained on 2.5m NAIP upsampled 2× via bicubic interpolation; no true sub-2.5m physical information existed in the training target.
- **Status:** Folder 05 and Folder 07 are formally marked **DEPRECATED/ARCHIVED**. Validated project scope is strictly centered on **10m $\rightarrow$ 2.5m super-resolution**.

### 3. Legacy Full-Scene Figures (`SEN2SR_10Band_3Way_Comparison.png`, `SEN2SR_10Band_Difference_Maps.png`)
- **Audit Finding:** Demonstrates seamless full-scene tiled inference with 2D Hann window blending over Copernicus satellite captures.
- **Disclaimer:** Copernicus scenes lack coincident sub-meter aerial ground truth. Spatial gradient metrics on these scenes indicate relative edge sharpness, not ground-truth accuracy.
